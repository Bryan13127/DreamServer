# Temporary Test Credentials & Test Mode\n\nThis guide explains how to use temporary test credentials and test mode with the Instagram API fetcher.\n\n## Quick Start with Test Mode\n\n### Option 1: Run with Mock Data (No API Credentials Needed)\n\n```bash\nnode fetch-userdata.js --test\n```\n\nThis will:\n- Use mock Instagram business account data\n- Display sample media posts\n- NOT make any actual API calls\n- Perfect for testing and demonstration\n\n### Option 2: Use Temporary Test Credentials File\n\n```bash\n# Use the .env.test file with placeholder credentials\nnode fetch-userdata.js --env .env.test\n```\n\n**Note:** The `.env.test` file contains placeholder values. For actual API calls, you need real credentials.\n\n### Option 3: Provide Credentials via Command Line\n\n```bash\nnode fetch-userdata.js --token YOUR_ACCESS_TOKEN --account YOUR_ACCOUNT_ID\n```\n\nExample:\n```bash\nnode fetch-userdata.js --token EAABsbCS1iHgBAPz123abc... --account 123456789012345\n```\n\n## Understanding Test Mode\n\nTest mode provides **realistic mock data** for development and testing:\n\n### Mock Account Data\n```javascript\n{\n  username: 'test_instagram_account',\n  name: 'Test Instagram Account',\n  followers_count: 1234,\n  follows_count: 567,\n  media_count: 89,\n  biography: 'This is a test account for API demonstration 🚀'\n}\n```\n\n### Mock Media Posts (5 samples)\n- Beautiful sunset with 1,543 likes\n- Coffee time post with 892 likes\n- Weekend vibes with 2,156 likes\n- Coding session with 654 likes\n- Project launch with 3,421 likes\n\n## Getting Real Credentials\n\nWhen you're ready to use real Instagram data:\n\n### Step 1: Create Facebook Developer Account\n1. Visit [Facebook Developers](https://developers.facebook.com/)\n2. Sign in with your Facebook account\n3. Click \"My Apps\" → \"Create App\"\n4. Choose \"Business\" as the app type\n\n### Step 2: Set Up Instagram API\n1. In your app dashboard, find \"Instagram Basic Display\"\n2. Click \"Set Up\"\n3. Accept terms and select your Instagram business account\n\n### Step 3: Generate Access Token\n1. Go to Tools → Graph API Explorer\n2. Select your app from the dropdown\n3. Click \"Generate Access Token\"\n4. Select these permissions:\n   - `instagram_business_profile_get_account_info`\n   - `instagram_business_read_media`\n5. Copy the generated token\n\n### Step 4: Get Business Account ID\n1. Make a Graph API call: `GET /me?fields=id`\n2. Your business account ID will be in the response\n\n### Step 5: Store Credentials\n\nEdit `.env` file:\n```env\nINSTAGRAM_ACCESS_TOKEN=EAABsbCS1iHgBAO7ZCe...your-token-here...\nINSTAGRAM_BUSINESS_ACCOUNT_ID=123456789012345\n```\n\nThen run:\n```bash\nnode fetch-userdata.js\n```\n\n## Command-Line Options\n\n```bash\n# Help\nnode fetch-userdata.js --help\n\n# Test mode (mock data)\nnode fetch-userdata.js --test\n\n# With CLI token and account ID\nnode fetch-userdata.js --token ABC123 --account 987654\n\n# Load from custom .env file\nnode fetch-userdata.js --env .env.production\n\n# Verbose logging\nnode fetch-userdata.js --verbose\n\n# Combine options\nnode fetch-userdata.js --test --verbose\n```\n\n## Test Mode Output Example\n\n```\n⚠️  TEST MODE ACTIVE - Either:\n- Get real credentials from Facebook Developer Portal, or\n- Use `--test` flag for mock data\n\n### Issue: \"API Error: 401 Unauthorized\"\n**Causes:**\n- Token has expired\n- Token has wrong permissions\n- Business account ID is incorrect\n\n**Solution:**\n- Regenerate token from Graph API Explorer\n- Verify permissions are set correctly\n- Confirm account ID matches your business account\n\n### Issue: \"Network Error: Unable to reach Instagram API\"\n**Causes:**\n- No internet connection\n- Network firewall blocking access\n- Instagram API temporarily down\n\n**Solution:**\n- Check internet connection: `ping google.com`\n- Try test mode: `node fetch-userdata.js --test`\n- Try again in a few moments\n\n## Development Workflow\n\n```bash\n# 1.
